# AxiOwl Web Theme

`axiowl-theme.tokens.json` is the public web theme contract for the AxiOwl documentation site. It mirrors the semantic values used by the native AxiOwl application theme without importing React Native code into Docusaurus.

The GitHub Pages workflow generates web CSS from this file. Update the contract when the AxiOwl brand theme changes; do not hand-maintain a second CSS palette.
