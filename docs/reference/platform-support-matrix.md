# Platform Support Matrix

| Platform or role | Product experience | Main capabilities |
|---|---|---|
| Windows x64 desktop | Primary host | Provider packages, mailbox, MCP, A2A, SSH, Mobile App tab, Node or native daemon, MSI |
| Linux x86-64 desktop | Native host | C++ desktop, provider assets, Debian package, bundled AxiOwl daemon and service |
| macOS desktop | Native host | Swift CLI/GUI, provider workflows, mailbox, bundled AxiOwl daemon, signed package pipeline |
| Android | Mobile client | QR/link pairing, host registry, relay/direct routes, providers, projects, agents, timelines, permissions |
| iPhone | Mobile client | Native host pairing, relay/direct connectivity, agent sessions, turns, and timelines |
| Hosted relay | Network service | Encrypted client-to-daemon frame routing across networks |
| A2A server/client | Standards role | Agent Cards, messages, tasks, results, and artifacts |

## Shared Connected Model

Desktop hosts own provider processes, projects, sessions, and timelines. Mobile clients pair to those hosts and control agents through relay or direct connections. A2A remains a separate standards-based endpoint model.

Explore the [Platform Guide](../platforms/README.md) for narrative platform pages.
