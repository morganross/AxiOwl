# AxiOwl Mailbox

AxiOwl Mailbox is the built-in local coordination endpoint. It gives users a familiar place to receive messages, inspect results, and launch provider workflows.

## What It Provides

- a stable built-in registry target;
- a local inbox for AxiOwl messages;
- result and receipt visibility;
- bounded provider test plans;
- a coordination surface independent of any external AI provider.

The mailbox is a single core endpoint, so it is always easy to find and does not require provider sign-in.

It is useful as a home base for cross-provider workflows and as a visible destination for messages returned from agents or approved devices.
