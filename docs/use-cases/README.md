# What You Can Do With AxiOwl

AxiOwl turns separate AI sessions into an intentional working group. You can give each session a role, send work to the right specialist, collect replies, and keep the human in control of the overall direction.

The same model scales from two local chats to approved devices and standards-based external agents.

## One Simple Pattern

Most AxiOwl workflows follow the same pattern:

1. Give each session or agent a clear role.
2. Discover it and keep its provider-owned identity in the registry.
3. Send a focused request to the intended target.
4. Use the receipt to track the handoff.
5. Collect the correlated reply or task result.
6. Decide what should happen next.

This preserves the strengths of each provider while giving the overall workflow a shared language for targets, messages, receipts, and replies.

## The Human Stays In Charge

AxiOwl is coordination software. It helps move work and evidence between tools; it does not take ownership of your project decisions. You choose the agents, the roles, the routes, and the point at which a result is ready to use.
