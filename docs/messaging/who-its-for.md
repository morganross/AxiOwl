# Who Messaging is for

Messaging is useful when relevant work lives in more than one AI conversation and manually moving instructions between them has become part of your day.

## Individual developers

Keep implementation in one conversation and ask an independent conversation to examine a specific change. Send the objective and an accessible reference instead of pasting the entire working history.

You retain control over the provider account and tools used by each participant. AxiOwl does not choose a cheaper model or change a provider subscription for you.

## People coordinating several agents

Give each conversation a clear responsibility: implementation, review, documentation or investigation. Use explicit messages for handoffs while keeping detailed exploration in the conversation doing the work.

Messaging transports those instructions. Ownership of files, merge decisions, approvals and conflicting edits still needs coordination.

## People working across computers

Address an agent on a configured development computer without treating it as a local chat. The remote computer continues to own its files, provider processes and authentication.

This fits a specialist working in a different checkout or operating system. The recipient needs access to every file or artifact referenced in the message.

## Teams and administrators

Install a consistent integration setup, document approved remote routes and manage signed updates. Keep provider access, AxiOwl account access, device approval and SSH authorization separate.

The presence of administrative controls is not a claim of enterprise role-based access control, compliance certification or a hosted team-management service.

## Choose another tool when appropriate

For a single conversation with no external handoffs, the provider's own interface may be sufficient. For a complete conversation-and-project workspace, see [AxiOwl IDE](../ide/README.md). For access from a phone, see [AxiOwl Mobile](../mobile/README.md).

Messaging can reduce manual copying and make responsibilities clearer. It does not guarantee lower token costs, faster completion or correct agent output.
